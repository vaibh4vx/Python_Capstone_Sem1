# FreshFlow – Data Analytics Project

## 📌 Project Overview

FreshFlow is an end-to-end data analytics project built using Python and NumPy. It focuses on analyzing retail sales data to understand business performance, profitability, sales trends, and unusual transactions.

## 🎯 Project Objectives

- Inspect and clean sales data.
- Perform exploratory data analysis (EDA).
- Calculate revenue, cost, and profit metrics.
- Compare product, outlet, and category performance.
- Analyze daily sales trends and discounts.
- Detect anomalies in transactions.
- Perform what-if scenario analysis.
- Validate results using NumPy.

## 🛠️ Technologies Used

- Python
- NumPy
- CSV

## 📈 Key Findings

- Analyzed 5,000 sales records.
- Identified 28 missing cells and 36 suspicious records.
- Net Revenue: ₹15.94 Lakh
- Gross Profit: ₹8.29 Lakh
- Overall Profit Margin: 52.05%
- Product 6 generated the highest revenue and gross profit.
- Higher discount levels were associated with lower profit margins.
